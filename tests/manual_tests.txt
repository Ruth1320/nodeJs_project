General Notes:
The project includes four RESTful services:
1. logs service - port 4001
2. users service - port 4002
3. costs service - port 4003
4. about service - port 4004

All services are connected to MongoDB Atlas database: costmanager.
The tests were performed manually using the browser and PowerShell.
